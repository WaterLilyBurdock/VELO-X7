# VELO X7 — Карбоновые велосипеды и Motion-графика

Лендинг веломастерской **VELO X7** без 3D-графики — полностью на **2D Motion-графике** с анимациями **GSAP + ScrollTrigger** и плавным скроллом **Lenis**.

## Особенности Motion-дизайна
- **Векторная сцена велосипеда**: отрисовка карбоновой рамы (`strokeDashoffset`), вращение спиц колёс и шатунов, аэродинамические потоки и бегущая дорожная разметка.
- **Интерактивные режимы**: переключение темпа (`Спринт`, `Круиз`, `Подъём`) плавно меняет скорость всей кинетики (`timeScale`) и телеметрию, а палитра перекрашивает раму.
- **Типографика и скролл**: бегущая строка-тикер, появление заголовков из масок, счётчики характеристик (`7.4` кг, `22` скорости, `28` мм), магнитные кнопки и кастомный курсор.
